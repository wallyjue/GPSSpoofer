GPSSpoofer

在 Mac 上模擬 iPhone 的 GPS 位置 Simulate your iPhone's GPS location from a Mac

在地圖上點一下，或規劃一條多點路線，USB 連接的 iPhone 就會回報這個位置。原理和 Xcode 的「Simulate Location」相同，不需要越獄，也不需要 sudo。 Click the map or plan a multi-stop route, and the iPhone on USB reports that location. It uses the same service as Xcode's Simulate Location, with no jailbreak and no sudo.

功能 Features

點地圖就傳送Click to teleport

在地圖上點選目標，可以立即套用到 iPhone，也可以直接輸入或貼上經緯度。Pick a spot on the map and apply it right away, or type or paste coordinates.

地點搜尋Place search

用店名或地址搜尋 Apple 地圖，以目前畫面為中心排序結果，一鍵設為目標或加入路線。Search Apple Maps by name or address around the current view, then set a result as the target or add it to a route.

多點路線Multi-stop routes

依序走過多個路線點，終點可以停止、循環或來回往返，並顯示全程距離與預估時間。Travel through waypoints in order. At the end, stop, loop back or go back and forth. Distance and travel time are shown.

可調速度Adjustable speed

1–120 km/h，有步行、慢跑、單車、汽車快捷鍵，以及會記住數值的自訂速度。移動途中調整立即生效。1 to 120 km/h with walk, jog, bike and car presets, plus a custom speed that is remembered. Changes apply while moving.

三種底圖Three map layers

標準、衛星、混合，另有 3D 建築與地形，以及即時路況。Standard, satellite and hybrid, with optional 3D buildings and terrain and live traffic.

四種語言Four languages

繁體中文、简体中文、English、日本語，在 App 內切換，立即生效。Traditional Chinese, Simplified Chinese, English and Japanese, switchable in the app without a restart.

運作方式 How it works

SwiftUI + MapKit AppSwiftUI + MapKit app → location_helper（Python） → pymobiledevice3 → USB → iPhoneUSB → iPhone

App 透過 stdin/stdout 的 JSON 和內附的 helper 溝通，helper 再用 DVT 的 LocationSimulation 服務設定位置。iOS 17 以上會自動建立 tunnel，iOS 16 以下改走 lockdown 服務。DMG 已內附 helper，不需要另外安裝 Python。 The app talks JSON over stdin/stdout to a bundled helper, which sets the location through the DVT LocationSimulation service. On iOS 17 and later it opens a tunnel automatically. On iOS 16 and earlier it uses the lockdown service. The DMG bundles the helper, so no Python install is needed.

開始使用 Getting started

需求Requirements

  • 搭載 Apple Silicon、macOS 14 以上的 MacAn Apple Silicon Mac on macOS 14 or later
  • 用 USB 連接、已信任這台 Mac 的 iPhoneAn iPhone on USB that trusts this Mac
  • iPhone 已開啟「設定 → 隱私權與安全性 → 開發者模式」Developer Mode turned on in Settings → Privacy & Security on the iPhone

安裝Install

  1. 從 Releases 下載 DMG，把 GPSSpoofer 拖進「應用程式」。Download the DMG from Releases and drag GPSSpoofer to Applications.
  2. 目前的版本是 ad-hoc 簽署，第一次開啟前在終端機執行：The build is ad-hoc signed. Before the first launch, run this in Terminal: 
    xattr -dr com.apple.quarantine /Applications/GPSSpoofer.app
  3. 在「裝置」分頁選擇 iPhone 並連線。第一次連線會掛載 Developer Disk Image，大約需要數十秒。Pick your iPhone in the Device tab and connect. The first connection mounts the Developer Disk Image, which can take a minute.

從原始碼建置 Build from source 

git clone https://github.com/wallyjue/GPSSpoofer.git
cd GPSSpoofer
./scripts/setup.sh     # Python venv + pymobiledevice3
swift run              # or ./scripts/package.sh for a DMG

限制與注意事項 Limitations and notes

  • iOS 17 以上，模擬位置只在連線期間有效。中斷連線或關閉 App 後，iPhone 會回到真實位置。On iOS 17 and later, the simulated location lasts only while connected. Disconnecting or quitting restores the real location.
  • 中國大陸地區的 Apple 地圖使用 GCJ-02 座標，點選位置會與實際 WGS-84 位置偏移數百公尺。In mainland China, Apple Maps uses GCJ-02 coordinates, so picked points are offset by a few hundred meters from WGS-84.
  • 目前只提供 Apple Silicon（arm64）版本。Only Apple Silicon (arm64) builds are provided.

這個工具適合開發與測試定位相關的 App。許多 App 和遊戲的服務條款禁止偽造位置，使用前請確認，風險由使用者自行承擔。 This tool is meant for developing and testing location-aware apps. Many apps and games forbid spoofed locations in their terms of service. Check before you use it, and use it at your own risk.
